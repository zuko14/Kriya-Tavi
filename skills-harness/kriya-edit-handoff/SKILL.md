# Finishing in another editor

1. **Which editor?** Premiere, Final Cut, DaVinci Resolve, or plain files. One handoff package serves all of them: OTIO, FCPXML, EDL and captions.
2. **Say what doesn't travel.** Each format drops something (speed changes, freezes, motion titles, effects). Read the package's list of omissions to the person, item by item.
3. **Media relink.** The package links the original files; moved to another computer, they relink from the manifest. Sources are never copied or changed.
4. **Chapters and markers** travel as markers.
5. **Check the import** if the person can: same length, same cuts.

**Done when** the person has the package, knows what to redo by hand, and how to relink.
