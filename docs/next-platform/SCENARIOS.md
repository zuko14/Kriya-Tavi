# Real-world scenarios (track N)

What people in India actually hand an agent, and the route Kriya takes for
each. The route column uses only capabilities that exist or that this
track designs; where the honest answer is "the person does this step", it
says so. Each scenario feeds a golden test (NG-, EVALUATION_PLAN §2) or a
paid evaluation case.

Routes: **API** (official connector in `lib/connectors*`), **App** (a
registry MCP server, track N), **Browser** (`kriya-browser`, site modes,
`assisted` by default), **Call** (voice track, person confirms each call),
**Job** (track O mandate), **Kit** (K9 ready-to-apply text), **Hand-off**
(R5: the person does it).

## Why some routes are hand-offs

R5 never becomes a tool (AD-04, OD-12, ND-19). Indian agent-payment rails
(UPI Reserve Pay, NPCI's planned agent protocol) exist only at demo or
protocol stage as of 2026-10-24 (COMPETITOR_RESEARCH §1.5, Secondary).
Kriya's answer is preparation, reminders by phone call, and an honest
hand-off, so "delivered" never includes a step the person took outside.
