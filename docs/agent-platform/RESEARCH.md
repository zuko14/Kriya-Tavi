# Research: market, infrastructure, memory, platform rules, India

Researched 2026-10-17. Each finding carries a **confidence** label:
**Primary** (read on the vendor's or regulator's own page), **Secondary**
(third-party summary, needs a primary check), **Background** (general
knowledge of the field, not re-checked today). Anything a phase depends on
has a verification step and a blocker id. Don't build on a Secondary finding
without doing its check first.

## 1. What comparable products do (Background)

| Product type                                                                                                      | Pattern worth copying                                                                                            | Pattern we avoid                                                            |
| ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| General browsing agents in chat assistants (e.g. ChatGPT's agent mode, Google's agent features, Claude in Chrome) | The person takes over for logins and CAPTCHAs; confirmation before consequential actions; a visible live browser | Broad autonomy on any site; storing passwords                               |
| Agentic browsers (e.g. Perplexity Comet)                                                                          | Work done inside the person's own signed-in session                                                              | Prompt-injection exposure from acting on every page with full session power |
| Autonomous "do anything" agents (e.g. Manus)                                                                      | Long-running tasks with a visible plan and a final artifact                                                      | Opaque runs; claims of completion without evidence                          |
| Memory layers (Mem0, Zep/Graphiti, Letta)                                                                         | Extract-then-reconcile writes, temporal validity, hybrid retrieval, a small always-loaded core plus retrieval    | An external memory service holding personal data outside our RLS            |

**Gap in the Indian market (Background):** no product combines Indian
languages, rupee/GST-correct money handling, Indian portals and exams,
evidence-backed action records, and phone-call reminders. Kriya's
differentiation is **verified action, India-correct**, not raw autonomy.

**Observation format for the model (Background).** An accessibility-tree
snapshot with element references (the approach of Playwright's own MCP
server) costs far fewer tokens than screenshots and gives exact targets.
Screenshots are kept as evidence and used only when the tree is insufficient
(canvas, image-only buttons).

**Decision link:** AD-08. **Verify in A4:** sessions per instance and memory
per session on the target Render plan; Chromium sandbox under Render; cold
start. **Verify in A10:** benchmark self-hosted against one managed vendor on
the fixture suite (success, latency, cost per session-minute from a written
quote).

## 3. Memory and context

| Finding                                                                                                                                                                                                                                                        | Confidence                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Mem0 paper (arXiv [2504.19413](https://arxiv.org/pdf/2504.19413)): extract-and-reconcile memory (add/update/delete/no-op) instead of replaying full history, with large token savings versus full-context baselines on LOCOMO. Exact figures not re-read today | Primary source exists; figures Secondary                                                |
| Zep/Graphiti (arXiv 2501.13956): bi-temporal facts. Each fact has when it was true and when it was recorded, and a changed fact is invalidated, not overwritten; hybrid retrieval (semantic + keyword + graph)                                                 | Secondary ([summary](https://atlan.com/know/zep-vs-mem0/))                              |
| Vendors dispute each other's LOCOMO numbers; no benchmark is settled                                                                                                                                                                                           | Secondary                                                                               |
| OpenRouter prompt caching: automatic for OpenAI, DeepSeek and Gemini; Anthropic (and reportedly Alibaba) need `cache_control`; sticky routing keeps a conversation on the same endpoint when cache reads are cheaper                                           | Primary ([docs](https://openrouter.ai/docs/guides/best-practices/prompt-caching))       |
| OpenRouter offers an embeddings API (`/embeddings`, models such as `openai/text-embedding-3-small`)                                                                                                                                                            | Primary ([docs](https://openrouter.ai/docs/api-reference/embeddings))                   |
| PGlite supports pgvector, but the installed `@electric-sql/pglite` 0.5.10 exports no `vector` subpath (checked in `node_modules` today); the docs point to a separate package `@electric-sql/pglite-pgvector`                                                  | Primary (local check) + Secondary ([pglite extensions](https://pglite.dev/extensions/)) |
| Postgres full-text search (`tsvector`, `ts_rank_cd`, `websearch_to_tsquery`) is built in, works in PGlite and Supabase without extensions                                                                                                                      | Background; **verify in A1 with a test**                                                |

**What this means (AD-09, AD-10, AD-12):** copy the _ideas_: reconcile on
write, temporal validity, a small core plus retrieval, hybrid search. Keep
the data in our Postgres under RLS. Measure before adding vectors.

## 5. India: tax, data protection, money

| Finding                                                                                                                                                                                                                                            | Confidence                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GST e-invoicing is mandatory once aggregate turnover crossed ₹5 crore in any year since 2017-18 (in force since 1 Aug 2023); a 30-day reporting window applies to AATO ≥ ₹10 crore (from 1 Apr 2025 per most sources)                              | Secondary ([summary](https://www.gimbooks.com/blog/5-crore-e-invoice-turnover-rule-2026/amp/)). **A7 does not generate IRNs**; Kriya flags when e-invoicing likely applies and tells the person to use their GST/e-invoice system                                                                                |
| GST invoice serial number: unique, consecutive, ≤ 16 characters, per financial year (CGST Rule 46)                                                                                                                                                 | Background; **verify the rule text in A7**                                                                                                                                                                                                                                                                       |
| GSTIN: 15 characters (state code, PAN, entity number, `Z`, check character) with a published checksum algorithm                                                                                                                                    | Background; **verify the algorithm against a primary source in A7 and test with real public GSTINs**                                                                                                                                                                                                             |
| DPDP Rules 2025 notified in November 2025 (13 or 14 Nov per source), phased: Board provisions at once; consent-manager provisions after about a year; notice, consent, security safeguards and breach intimation after 18 months (around May 2027) | Secondary ([PIB PDF](https://static.pib.gov.in/WriteReadData/specificdocs/documents/2025/nov/doc20251117695301.pdf), [Deccan Herald](https://www.deccanherald.com/amp/story/india%2Fcentre-notifies-dpdp-rules-implementation-planned-in-phases-spread-over-12-18-months-3798465)).
