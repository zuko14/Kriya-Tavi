## What it shows

- **Paraphrases (0 / 10):** full-text search can't match a question with
  no words in common ("How much can I spend on a new computer?" vs "Laptop
  budget is ₹80,000"). Each planted note ranked 7th, behind six fresher
  unrelated notes. This is the gap MEMORY_AND_CONTEXT §10 and AD-09 foresaw:
  embeddings are the planned answer (A9, only if M1 < 0.90 after tuning).
- **Old notes (1 / 5):** these _do_ share words with the question, yet
  lose to fresh unrelated notes: a two-word match scores about 0.17, while
  a one-day-old note of the agent's own gets about 0.59 from recency,
  importance and the agent bonus. This is AF-24 at scale, and it is a
  ranking choice, not an FTS limit.
- Safety held everywhere: no superseded value reached the prompt, no
  injected note reached the always-on block, and every sensitive value was
  refused.

## Options (owner's decision, AD-25; each measured on this suite first)

1. **Matches first:** notes that match the question's words always rank
   above notes that don't, and recency orders within each group. Expected
   to fix the gap family; it can't fix paraphrases.
2. **Re-weight:** raise the text term (or use a rank normalisation that
   doesn't shrink short matches) against recency and the agent bonus.
3. **Embeddings (A9):** the documented path for paraphrases; needs pgvector
   on Supabase, a PGlite check (RG-8), and an embedding cost.

## Limits

- No model answered anything: M2 is measured as "the old value never
  reaches the prompt", which is necessary but not sufficient for "the model
  never answers with it".
- The 40 ordinary notes are one fictional person's; real memory sizes and
  ages vary. Ages here: ordinary notes 1–90 days; planted notes 11–20
  (fact), 15 (lang), 20 (paraphrase), 30 (update), 5 and 40
  (contradiction), 660–700 days (gap).
