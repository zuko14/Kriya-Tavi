## Limits of this measurement

- Free run: the steps are scripted, so B1 measures that the browser path
  does what each step should (navigation, refusals, guard, hand-off), not
  how well a model chooses steps. A paid run needs the owner's go-ahead.
- AS-SEC families 03 (memory poisoning) and 05 (skills) are not browser
  tests here; 03 is covered by AS-MEM-INJ (A1), 05 waits for A9.
- With the read-only runner, no scenario can show an approved commit; the
  evidence of one is tested at provider level (AT-BRW-05, status.md).
