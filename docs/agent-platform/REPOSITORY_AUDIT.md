Read 2026-10-17 at commit `bdf223f`, with uncommitted voice-track docs present.
Baseline: `npm run check` passes (82 tests / 9 files, per `status.md` Phase 0
check log). "The code is the fact": where a document disagrees with the code,
the code wins and the conflict is recorded.
