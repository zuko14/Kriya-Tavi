## 5. Preflight for every session

1. `git status --short` — anything you didn't make: stop and ask; never
   discard it.
2. `npm run check` passes (after P-1). If it fails before you start: stop.
3. Every decision your phase lists is Approved in "Track O owner
   approvals".
4. Your phase and the files you'll hold are free on the Coordination
   board; claim them.
5. A migration timestamp is claimed on the board and sorts last.

## 6. Stop conditions

Stop and ask the owner when:

- you'd touch a §1 file or a file not in §3;
- an existing test fails and the cause isn't clearly your change;
- the AI SDK, a table or a function behaves differently from these
  documents (record it as a new OF id in VISION_AND_GAP_ANALYSIS §5);
- you're about to make a tool grantable, add an evidence kind, or raise a
  limit in DECISIONS;
- you need a secret, an account, money, a deploy, a real model call, a real
  connector call, a real phone call or a real site;
- a grant would apply outside its mandate's goal thread (or its crew part
  threads), or to R4/R5;
- a local run, test or script would reach the live database: `.env`,
  `.env.local` and `npm run dev:worker` point at it (UI_VERIFICATION.md §1).
  Run `npm run verify:guard` first; if it fails, stop.
